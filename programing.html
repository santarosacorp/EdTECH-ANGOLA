1. Lógica de Programação & Portugol

Pensamento computacional, variáveis e estruturas de controlo

4 Pilares Computacionais

  • Decomposição: Divisão em subproblemas menor.
  • Padrões: Identificação de repetições.
  • Abstração: Foco no modelo essencial.
  • Algoritmos: Sequência finita e precisa de passos.

Estruturas de Controlo

  • Condicional: Se / Senão / Escolha
  • Laço Enquanto: Testa a condição no início.
  • Laço Repita: Executa ao menos 1 vez.
  • Laço Para: Iterações contadas e fixas.

Exemplo em Pseudocódigo (Portugol): Controlo de Temperatura

Algoritmo Sistema_Controlo_Temperatura
Var
    temperatura, limiteMaximo : Real
    sistemaAtivo : Logico

Inicio
    limiteMaximo <- 45.0
    Escreva("Introduza a temperatura do sensor (°C): ")
    Leia(temperatura)

    Se (temperatura > limiteMaximo) Entao
        sistemaAtivo <- Verdadeiro
        Escreva("ALERTA: Ativar refrigeração de emergência!")
    Senao
        sistemaAtivo <- Falso
        Escreva("Temperatura dentro dos limites operacionais.")
    FimSe
FimAlgoritmo

2. Linguagem Python: Automação & Análise

Sintaxe limpa, estruturas dinâmicas e processamento de dados

Análise de Sensores com Funções e Dicionários

def analisar_leituras(leituras, limite_alerta):
    if not leituras:
        return "Sem dados disponíveis."
    
    media = sum(leituras) / len(leituras)
    return {
        "media": round(media, 2),
        "pico": max(leituras),
        "alerta": media > limite_alerta
    }

# Amostras do sensor de temperatura
amostras = [32.5, 34.0, 36.8, 41.2, 39.5]
relatorio = analisar_leituras(amostras, limite_alerta=35.0)
print(f"Média: {relatorio['media']}°C | Alerta: {relatorio['alerta']}")

3. C / C++ & Programação de Hardware

Ponteiros, gestão de memória e microcontroladores (Arduino/ESP32)

Controlo de Relé com Leitura Analógica (C++ / ESP32)

const int PIN_SENSOR = A0;
const int PIN_RELE = 13;

void setup() {
    pinMode(PIN_RELE, OUTPUT);
    pinMode(PIN_SENSOR, INPUT);
    Serial.begin(9600);
}

void loop() {
    int leitura = analogRead(PIN_SENSOR);
    if (leitura > 600) {
        digitalWrite(PIN_RELE, HIGH); // Liga atuador
    } else {
        digitalWrite(PIN_RELE, LOW);
    }
    delay(500);
}
